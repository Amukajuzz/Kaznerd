# Raw data

`IOB2_train.txt`, `IOB2_valid.txt`, `IOB2_test.txt` — the **KazNERD** corpus
(https://github.com/IS2AI/KazNERD), CoNLL-2002 format with IOB2 tags,
licence CC BY 4.0.

Yeshpanov R., Khassanov Y., Varol H. A. (2022). KazNERD: Kazakh Named Entity
Recognition Dataset. LREC 2022.

If the files are missing, the program downloads them automatically on first run.
